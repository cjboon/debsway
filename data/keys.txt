  KEYS                                   Super = the Windows / Cmd key
  ──────────────────────────────────────────────────────────────────
  Press Esc to close this; arrows and Space scroll.
  Open it again any time: Super+?, click debsway > Help in the bar, or type  keys.
  (The debsway menu: arrows and Enter, or click. Esc closes every screen of it.)
  Lines for things you have not installed are left out; add them with debsway --apps.
  It is also the file ~/KEYS.txt.
  The key every sway shortcut starts with: keys --mod alt, or keys --mod super.

  START HERE
    Super+Enter            terminal (foot)
    Super+d                launcher: type a name, Enter, e.g.
                           firefox, incognito, keepassxc, sparrow
    Super+Shift+q          close the window
    Super+?                this page

  IN THE TERMINAL (foot)
    Ctrl+Shift+c / v       copy / paste (Ctrl+c stops a program)
    Shift+PageUp / Down    scroll back / forward
    Ctrl+plus / minus      bigger / smaller text (Ctrl+0: normal)
    Ctrl+Shift+n           another terminal, in the same folder

  IN PROGRAMS (Firefox, Mousepad, Thunar, ...)
    Ctrl+w                 close the tab (or the window, if it has no tabs)
    Ctrl+q                 quit the program, all its windows
                           (in the terminal Ctrl+w deletes a word instead:
                           close it with Super+Shift+q or by typing exit)

  WINDOWS
    Super+h j k l          move focus left / down / up / right (or arrows)
    Super+Shift+h j k l    move the window (or Shift+arrows)
    Super+f                fullscreen
    Super+b / Super+v      next window opens beside / below
    Super+w / Super+s      tabbed / stacked layout
    Super+e                switch windows between beside / below each other
    Super+Shift+space      float / unfloat the window
    Super+r                resize mode: arrows or h j k l, Enter when done
    Super+drag             move a window; right-drag resizes it

  WORKSPACES
    Super+1 … 0            go to workspace 1 … 10
    Super+Shift+1 … 0      send the window to workspace 1 … 10

  SCREEN AND SOUND
@if brightness
    Brightness keys        brightness down / up (or Super+F1 / Super+F2)
    Bar: bright            scroll over it to change it
@end
@if volume
    Volume keys            volume down / up / mute, mic mute
                           (or Super+F11 / Super+F12 / Super+F10)
    Bar: vol               scroll over it to change it; click: mute
@end
    Bar: bat               click for the time left on the battery
    Super+Escape           lock the screen (type your password to unlock)
@if lid
    Close the lid          locks and turns the panel off; the laptop stays on
                           (alarms ring). Power it off before packing it
@end
@if screenshot
    Print                  screenshot of the whole screen to ~/Pictures
    Super+Shift+s          drag a region, saved to ~/Pictures
    Super+Shift+x          drag a region, copied to the clipboard
@end

  TIMERS AND ALARMS
    Super+t                menu: type 10m, 1h30 or 7:30 and press Enter
    Click the time         the same menu, with today's date at the top (even if the bar
                           hides it); Esc closes it
    timer 10m tea          from a terminal; timer at 7:30 wake up
    timer list | cancel    what is running | stop one (timer cancel all)
    timer stop             end the sound of a ringing alarm (or click/dismiss its notice)
    timer clock            show or hide the date in the bar
@if debsway-idle
    timer lock 10          lock the screen after 10 minutes idle (1 to 120; it
                           fades for 30 seconds first). timer lock: how long now
@end

  NOTIFICATIONS
    Super+n                dismiss one
    Super+Shift+n          dismiss all

  SESSION
    Super+Shift+c          reload the sway config
    Super+Shift+e          exit sway
    Super+Shift+Escape     power menu: lock, suspend, log out, reboot

  IF YOU GET STUCK
    Ctrl+Alt+F2            a plain text console: log in there and fix things
    Ctrl+Alt+F1            back to the desktop
    Super+Shift+Escape     power menu: log out, reboot, power off
