Install Wren Linux

Install

About an hour, most of it waiting. You need a computer you can erase, a USB stick, and an internet connection. This erases the whole disk.

  1. Set up the BIOS: UEFI only, Secure Boot on, storage mode AHCI. The BIOS guide says how.
  2. Install Debian 13 from debian.org. Leave the root password empty, choose "Guided - use entire disk and set up encrypted LVM" (five or six random words as its passphrase), and tick only "standard system utilities".
  3. Get Wren Linux, logged in on the text console: 
    sudo apt install git
git clone @GIT_URL@ ~/wren
  4. Check it before you run anything: Verify shows how, in three commands.
  5. Start: 
    bash ~/wren/start.sh
    It explains what it will do, and asks before changing anything.
