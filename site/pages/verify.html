Verify Wren Linux

Verify

Every Wren Linux update is signed by this key. After the install your computer checks it by itself, and refuses anything else. The first download is the one to check by hand.

@FPR_SPACED@

Compare it in two places that don't depend on each other: this page, SECURITY.md on GitHub@ONION_COMPARE@. Someone who changed one would have to change them all.

In your copy (~/wren, from Install):

grep '^WREN_SIGNING_FPR=' ~/wren/pins.sh
gpg --show-keys --with-fingerprint ~/wren/data/wren-signing-key.asc
git -C ~/wren -c gpg.program=gpg verify-commit HEAD

The first two must both show the key above. For the third, first import the key (gpg --import ~/wren/data/wren-signing-key.asc); it must say "Good signature" from that key. If anything differs, don't run it: SECURITY.md says whom to tell.
